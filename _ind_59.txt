## Livrable 2 — Refactor `MesureService::enregistrer()`

Remplacer l’écrasement silencieux par une logique historisée :

```php
public function enregistrer(Indicateur $indicateur, array $data, ?int $userId = null): Mesure
{
    $userId ??= auth()->id();
    $calc = $this->calculerTauxEtFeu($indicateur, (float) $data['valeur_realisee']);

    $existante = $indicateur->mesures()->where('periode', $data['periode'])->first();

    if ($existante?->statut === 'validee') {
        abort(422, 'Mesure validée : créez une correction via le workflow dédié.');
    }

    $payload = [
        'valeur_realisee' => $data['valeur_realisee'],
        'taux_atteinte' => $calc['taux_atteinte'],
        'feu' => $calc['feu'],
        'commentaire' => $data['commentaire'] ?? null,
        'statut' => 'saisie',
        'saisi_par' => $userId,
    ];

    if ($existante) {
        $this->historiser($existante, 'modification', $userId);
        $existante->update($payload);
        return $existante->fresh();
    }

    $mesure = $indicateur->mesures()->create($payload + ['periode' => $data['periode']]);
    $this->historiser($mesure, 'saisie', $userId, null, $mesure);

    return $mesure;
}
```

**Historiser aussi** dans `verifier()` et `valider()` :

| Action | Code `action` |
|--------|----------------|
| Vérification | `verification` |
| Validation | `validation` |

**Méthode privée `historiser()`** : persiste une ligne dans `historique_mesures` + appelle `AuditLogger::enregistrer()`.

### 4.1 Déplacer `calculerTauxEtFeu()`

```php
final class IndicateurPerformanceService
{
    public function calculerTauxEtFeu(Indicateur $indicateur, float $valeurRealisee): array
    {
        // logique actuelle de MesureService (identique)
    }

    public function ecartCible(Indicateur $indicateur, float $valeurRealisee): float
    {
        $cible = (float) ($indicateur->valeur_cible ?? 0);
        return round($valeurRealisee - $cible, 4);
    }

    public function tendance(Indicateur $indicateur, string $periodeCourante): ?array
    {
        $mesures = $indicateur->mesures()
            ->where('statut', 'validee')
            ->orderBy('periode')
            ->get(['periode', 'valeur_realisee', 'taux_atteinte']);

        $courante = $mesures->firstWhere('periode', $periodeCourante);
        $precedente = $mesures->where('periode', '<', $periodeCourante)->last();

        if (! $courante || ! $precedente) {
            return null;
        }

        return [
            'periode_precedente' => $precedente->periode,
            'valeur_precedente' => (float) $precedente->valeur_realisee,
            'valeur_courante' => (float) $courante->valeur_realisee,
            'variation_abs' => round((float) $courante->valeur_realisee - (float) $precedente->valeur_realisee, 4),
            'variation_pct' => (float) $precedente->valeur_realisee > 0
                ? round(((float) $courante->valeur_realisee / (float) $precedente->valeur_realisee - 1) * 100, 1)
                : null,
        ];
    }

    public function syntheseIndicateur(Indicateur $indicateur): array
    {
        $derniere = $indicateur->mesures()
            ->where('statut', 'validee')
            ->orderByDesc('periode')
            ->first();

        return [
            'code' => $indicateur->code,
            'libelle' => $indicateur->libelle,
            'cible' => (float) ($indicateur->valeur_cible ?? 0),
            'derniere_periode' => $derniere?->periode,
            'valeur_realisee' => (float) ($derniere?->valeur_realisee ?? 0),
            'taux_atteinte' => (float) ($derniere?->taux_atteinte ?? 0),
            'feu' => $derniere?->feu,
            'tendance' => $derniere ? $this->tendance($indicateur, $derniere->periode) : null,
        ];
    }

    public function feuxGlobaux(?int $exerciceId = null): array
    {
        // reprendre logique TableauBordService::feuxIndicateurs()
    }
}
```
